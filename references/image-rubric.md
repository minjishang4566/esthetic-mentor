# Image and Screenshot Rubric

Use this only after the user supplies visual material. Return observations, not a long inventory.

## Inspiration Images: Extract Visual DNA

| Lens | Look for | Express as |
| --- | --- | --- |
| Visual ancestry | Repeated historical or cultural signals: Bauhaus, postmodern furniture, Swiss editorial grids, folk craft, toy design, etc. | 1–3 influences plus the shared principle |
| Color roles | Background field, text/ink, structural neutral, active accent, occasional surprise | Role + approximate proportion such as `60 / 25 / 10 / 5` |
| Shape grammar | Rectilinear/organic, sharp/soft, cut-outs, frames, outlines, repetition | 3–5 rules, not adjectives |
| Composition | Grid, asymmetry, whitespace, layering, rhythm, density | What should transfer to an app layout |
| Type and icons | Editorial/neutral/expressive, weight contrast, icon stroke and corner behavior | A system character, not a font guess |
| Material and motion cues | Paper, plastic, ink, glass, physicality, restraint | Interaction consequences |

Identify a style as a **mixture** when that is more truthful, for example: “soft Bauhaus geometry with mid-century warmth.” State which influence controls layout and which controls personality. Do not stack labels merely to sound precise.

## Existing App Screenshots: Critique in This Order

1. Can a person see what matters and what to do next?
2. Does one visual hierarchy repeat consistently across screens?
3. Do color, shape, typography, iconography, and spacing point to the same personality?
4. Does the style match the app’s domain and intended feeling?
5. Which one edit would make the interface feel most intentional?

Phrase findings as: **evidence -> consequence -> repair direction**.

Example: “The blue appears both as the primary action and as large background decoration, so actions lose priority. Reserve saturated blue for decisions and give surfaces a quieter field.”

Never give a score without evidence. Limit first-pass critique to three findings unless the user requests an audit.
